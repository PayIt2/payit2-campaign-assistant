# PayIt2 2.1.0 implementation plan

**Spec:** `docs/specs/2026-11-08-claude-chatgpt-publishing-design.md`, Part 3.
**Depends on:** app-v2 B-436 (PR #1933): `update_campaign_settings` previews without `confirm: true`. 2.1.0 releases only after that is on prod.
**Branch:** `release/2026-11-09`.

## Format facts (OpenAI, checked 2026-11-08)

From developers.openai.com/plugins/build/plugins: root `plugin.json` (`$schema` `https://agent-plugins.org/schemas/1.0.0/plugin.schema.json`; OpenAI settings under `extensions["com.openai"]`: `onboardingSkill` path, `interface` with `displayName`, `shortDescription`, `longDescription`, `developerName`, `category`, `websiteURL`, `privacyPolicyURL`, `termsOfServiceURL`, `composerIcon`, `logo`); root `mcp.json` (`$schema` `.../mcp.schema.json`, server `type: "streamable-http"`, `url`, auth at `extensions["com.openai"].auth` with `type: "oauth"`, `client.mode: "dcr"`); `skills/<name>/SKILL.md`; `assets/`. Paths start with `./`. Plugins with hooks are not eligible for the public directory.

## Tasks

1. **Skills carry the baseline** (`campaign-context`):
   - Session start: with PayIt2 tools, call `list_my_campaigns` once and name any urgent campaign; without them, say nothing about sign-in until the organizer asks about live numbers. This is the ChatGPT `onboardingSkill`.
   - Campaign links: a `payit2.com/(fundraiser|event|group)/<slug>` link means fetch `get_campaign_overview` if tools are available, otherwise ask for the numbers. Skill descriptions name these links as a trigger.
   - Settings: call `update_campaign_settings` without `confirm` to get the server's preview, show it, call again with `confirm: true` after a clear yes. A theme-only call saves directly.
2. **Hook prompts once.** `confirm-settings-change.sh` asks only on a call carrying `"confirm": true`; the preview call and theme-only calls pass.
3. **Connection steps per chat.** Steps move out of `campaign` and `campaign-context` into `skills/campaign-context/references/connect.md` (Claude: Customize > Plugins, Connectors tab; Claude Code: `/mcp`, since prod accepts loopback sign-in since 2026-11-06). `openai/connect.md` (repo root, outside the Claude zip) holds the ChatGPT steps; `build-openai.sh` swaps it in. Deviation from the spec's two file names: one path the skills can name, so they need no per-chat branching.
4. **`build-openai.sh`** stages `dist/payit2-openai/` and zips `dist/payit2-openai.zip`: `plugin.json` built from `plugin/.claude-plugin/plugin.json`, `mcp.json`, `skills/` copied, the ChatGPT `connect.md`, `assets/icon.png`. Leaves out hooks, scripts, agents and `.claude-plugin/`; fails if anything else is left. Unit test runs it (CI runs it through `npm test`).
5. **Release.** `release.yml` builds and attaches both zips to the plugin's release. Deviation from the spec (marketplace release): that workflow already attaches the Claude zip.
6. **Version 2.1.0**, CHANGELOG, plugin README (Claude Code sign-in works; ChatGPT package), rebuilt Claude zip, `claude plugin validate plugin --strict`.
